### About me

I'm interested in more than getting a program to run — I want to understand **why and how it works**. I'm exploring compilers, operating systems, and systems programming while turning small ideas into applications people can use.

For me, building a project goes beyond working code. It also means getting the rules right, validating the data, and improving the experience through user feedback. I learn by experimenting, asking questions, and making things.

### Featured project

#### 🧩 [Word Game](https://github.com/mirac-guler/kelime-oyunu)

A browser-based take on a Turkish TV word-game format, with a cozy, nostalgic feel.

- Built with HTML, CSS, and vanilla JavaScript.
- Includes timers, letter hints, scoring, and a timed answer flow.
- Involved validating the question-and-answer pool and checking answer lengths.
- Features a responsive interface and an answer flow refined through user feedback.
